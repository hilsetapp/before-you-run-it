The checker looks for notable actions in the text. Results are clues to review, not proof that a script is safe or harmful.

PowerShell, Bash, sh, Windows batch files, and package.json are supported.
Rules look for known text patterns. A script may build commands dynamically or download code that is not visible here.
Stays on your deviceThe check runs in this browser tab.
Shows its evidenceEach finding includes a matching line from the script.
Does not run codeFiles are read as text. Commands are never launched.

How to read the results

The rules flag commands that can download and run code, change startup settings, touch sensitive files, or request elevated permissions. The same command can be part of a legitimate installer. Check the context and verify the source.

A clean report does not mean a file is safe.

This tool does not execute code or inspect binary files. It is not a replacement for antivirus software, an isolated virtual machine, or checking the publisher and file hash.
